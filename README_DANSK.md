# Gdańsk Companion

Dette er en gratis web-app/PWA til iPhone. Den kan deles med familien via ét link.

## Det simple setup

1. Opret gratis konto på GitHub.
2. Opret gratis konto på Vercel.
3. Opret et nyt GitHub-repository, fx `gdansk-companion`.
4. Upload alle filerne fra denne mappe til repository'et.
5. Gå til Vercel og vælg Add New Project.
6. Vælg dit GitHub-repository.
7. Tryk Deploy.
8. Send Vercel-linket til din hustru.
9. Åbn linket i Safari på iPhone.
10. Tryk Del -> Føj til hjemmeskærm.

## Gratis produkter

- GitHub Free
- Vercel Hobby/free plan

## Vigtigt

Favoritter, budget og noter gemmes lokalt på hver telefon. I deler samme app og samme faste indhold, men jeres personlige favoritter og noter synkroniseres ikke mellem telefonerne.

## Vercel-indstillinger

Vercel bør selv genkende appen som Vite.

- Build command: `npm run build`
- Output directory: `dist`

Hvis Vercel foreslår dette automatisk, skal du bare trykke Deploy.
